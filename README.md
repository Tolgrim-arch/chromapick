## 🚀 Features

### 🔍 Euclidean Color Extraction & Surgical Precision
Dynamically computes up to 12 dominant colors from any image using spatial color distance mathematics (Dominant, Vibrant, Warm, and Cold algorithms). Features a raw pixelated 8x zoom magnifier with a pixel-perfect crosshair grid for extreme targeting accuracy.

### ⚡ Offline First & Frictionless Workflows
Runs entirely in the browser using the HTML5 Canvas API. No server-side processing, no external API calls, zero privacy risks. Supports Drag & Drop, Click-to-upload, direct Ctrl+V clipboard pasting, and instant presets. Fully auto-translated into 14 languages based on your OS language.

## 🛠️ Tech Stack

- **Vanilla JavaScript** (Zero dependencies, pure DOM performance)
- **HTML5 Canvas API** (Raw pixel manipulation)
- **Modern CSS3** (Flexbox, Grid, custom properties, responsive media queries)

## 🎯 Usage

1. Open the [Web App](https://Tolgrim-arch.github.io/chromapick/) from your PC or Mobile device.
2. Paste (Ctrl+V), drag & drop, or select an image from your gallery.
3. Use the **Extractor** tab to get dominant palettes and filter by algorithm.
4. Hover/Touch the canvas to pick an exact pixel with the precision magnifying glass.
5. Save your favorite palettes to local storage, or use the **Converter** tab to get exact mathematical harmonies.
6. Click any color to instantly copy its HEX/RGB value to your clipboard.
